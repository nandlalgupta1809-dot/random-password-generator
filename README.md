# 🔐 Random Password Generator

A simple and responsive **Random Password Generator** built using **HTML, CSS, and JavaScript**.

This project generates random passwords using JavaScript and helps users create stronger passwords quickly and easily.

## ✨ Features

* 🔑 Generates random passwords
* ⚡ Fast and easy to use
* 🎨 Simple and clean interface
* 📱 Responsive design
* 🧠 Built using basic JavaScript concepts

## 🛠️ Technologies Used

* **HTML** — Structure of the webpage
* **CSS** — Styling and layout
* **JavaScript** — Password generation and functionality

## 🚀 How to Use

1. Clone this repository:

```bash
git clone https://github.com/nandlalgupta1809-dot/random-password-generator
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click the generate button to create a random password.
